## 两个参数

【Vue实例与对象的关系是 1：1】一个实例接管一个容器

- 后面的容器不生效、重复的Vue同挂载实例会报错

- 容器只能使用Vue实例提供的内容

  【`vm.$mount(el)` 把尚未挂载的实例挂载到指定元素；数据写在 `new Vue` 的配置对象里，不由 `$mount` 接收】

1. el：``"挂载点"`` 或者 `document.getElementById('id名')`  （字符串类型，指定Vue实例服务的容器）
   - 确定命中的元素及其内部的后代元素
   - 建议使用id选择器
   - 可以设置双标签(除了html和body标签)
2. data: 数据 （被el挂载的容器，才可以使用data里面的数据）
   - 可以写复杂类型 对象： obj、数组array、函数method等
   - `data()`也可以是一个函数，使用了**闭包**，必须返回一个对象
     - 让单页面的Vue达到各个组件有独立的私有变量空间，从而不会相互影响污染全局
     - **不建议使用了纯对象**，使得同名对象指向同一个内存空间地址，互相干扰
     - 此处的`this`指向`vue`实例对象 — Vue调用data函数
   - 在页面容器内使用data的值 `{{js表达式（会返回值的js代码） / data变量名}}`
   - data内的内容，会进行数据代理、数据劫持

```js
/* Vue.data的写法*/
new Vue({
	el:'#idName',
	data: { } /* 对象写法 */
	data(){   /* 匿名函数写法 */
		return{ name: "" }	
	}
	data:function(){ /* 函数写法 */
        return{ name:"" }
    }
	/* 一定不能用 箭头函数写法，箭头函数没有this，向上级找this=window是错误的，应该是Vue实例调用 */
})
```

## 数据代理

### 对象添加属性 defineProperty()

`Object.defineProperty( ObjectName, "属性名", {value: 属性值})`

该属性值不可以枚举 `Object.keys(person)`读取不到

- 使用场景：数据劫持、计算属性、数据代理

### Vue的数据代理

通过一个对象的代理对另一个对象中属性的操作（读、写）

```js
let obj = { x: 100 }
let obj2 = { y: 200 }
Object.defineProperty(obj2,'x',{
	get(){
		return obj.x; // obj2原本没有x属性值，它拿obj.x值作为自己的值
    },
    set(value){
        obj.x = value;  // 当有人修改obj2.x的值时，就是修改obj.x的值
    }
})

console.log(obj2.x); // 100  
obj2.x = 39;      // 通过obj2的代理，实现了obj中属性的操作
console.log(obj.x); // 39
```

在Vue中，实例`vm.data`的值，在实际中存放在 ·`vm._data`中，其数据劫持的实现功能：

`vm._data`存在一个数据劫持（劫持实现 数据变动，页面修改）；

- `vm`要读取 `_data`中的值，会在里面添加`name:getter`属性，可以以`{{name}}`读取到data里面的属性值
- `vm`要修改 `_data`中的值，会在里面添加`name:setter`属性，可以直接`vm.name = 19;`修改data里面的属性值

创建实例时传入的配置对象称为`options`，取里面的值的做`options.data`

【通过vm对象，代理data对象中的属性操作】

```js
const vm = new Vue({
    el:'#root',
    data:{
        name:"李四;
    }
})
vm.name = "王五"; 
// vm.name 触发了name属性的setter，其修改了data中的值变化
// 页面中的数据也会改变
```

页面中`{{name}}`为李四，当修改 `vm.name = '李四'` 时，data中的数据会变化，

## 数据劫持  观察者模式

如果有改动`_data_` — 即调用`.set`，则会调用视图更新

1. 使用定时器监视数据变动

```js
var data = {
    name: 'nni',
    address: 'ndd',
    list:[1,2,3,4],
    obj:{name:1,age:2}
}

// 监视改值-- 只能监视一个变量，执行操作
var tmp = 'nni'
setInterval(() => {
    if (data.name !== tmp) {
        tmp = data.name;
        console.log('data.name被修改，需要更新视图了');
    }
}, 1000); // 程序一直在执行
```

2. 手动添加 get、set — 陷入死循环

```js
// what? -- 手动给data添加 get、set
// how? -- 将会陷入死循环
// why? --
Object.defineProperty(data,'name',{
    get(){
        return data.name; // `.` == get(), 导致不断回调 get()
    },
    set( val ){
        data.name = val // `=` == set(), 导致不断回调 set()
    }
})
```

3. 观察者模式

```js
// 定义观察模式
function Observer(obj) {
    const keys = Object.keys(obj); // 拿到obj身上的所有属性
    keys.forEach((key) => { // 箭头函数，this指向Observer类
        Object.defineProperty(this, key, {  // 在Observer类上添加 obj上有的属性，并给每一个属性增加get、set
            get() { return obj[key] },
            set(val) { 
                obj[key] = val;
                // 属性值被修改，更新视图
                // updateView(JSON.parse(JSON.stringify(obj[key] = val)));
                if(Array.isArray(obj)){
                    obj.splice(key, 1, val); // 数组索引赋值不触发更新，用 splice
                }else{
                    obj[key] = val;
                }
            }
            // this是Observer，避免了调用和读取都是data导致的死循环
        })
    });
}
// 创建一个观察者
var obs = new Observer(data); // data中的数据被观察者监视

// 
var vm = {} // 模拟Vue实例对象
vm._data = data = obs;
```

## 视图监视数据更新

Vue会监视`data`中 <u>所有层级</u> 的数据

1. 通过`set()`实现监视
   1. 要在 new Vue 时传入需要监测的数据，才能实现检测
   2. 对象、数组中追加的属性，Vue默认不做响应式处理
2. 对象添加属性响应式：
   - `Vue.set(target, propertyName/index, value)`
   - `vm.$set(target, propertyName/index, value)`
3. 数组添加元素响应式：
   1. 通过重写数组 <u>更新元素</u> 的方法，实现响应式：
      - 调用原生对应的方法，对数组进行更新
      - 重新解析模板，对比不同，进而更新页面
   2. 必须调用 <u>原生的更新原生方法</u> ：push() pop() shift() unshift() splice() sort() reverse()
   3. 或者使用 <u>Vue.set() 和 vm.$set()</u> 方法
4. 数组使用 <u>不影响原数组的方法</u>（filter、concat、

:warning: Vue.set() 和 vm.$set 不能给vm或vm的根数据对象（包括`_data_`）添加响应式属性

```javascript
methods: {
    addObjSex() {
        this.$set(this.student, 'sex', "男")
        Vue.set(this.student,'sex','男')
    },
    addArrFri() {
        this.student.friends.unshift({name:'anmy',age:28})
        this.$set(this.student,'friends',[{name:'anmy',age:28},...this.student.friends])
        Vue.set(this.student, 'friends', [{ name: 'anmy', age: 28 }, ...this.student.friends])
    },
    updateArrFri() {
        this.student.friends.splice(0, 1, { name: "张三", age: 93 })
        this.student.friends[0].name = "张三"  // students.friends 作为数组没有 get、set；但数组项的属性有
    },
    addArrHobby() {
        this.student.hobby.push('学习')	
    },
    updateArrHobby() {
        this.student.hobby.splice(0,1,'开车')
        this.$set(this.student.hobby, 0, '开车')
    },
    removeArrHobby() {
        let hob = JSON.parse(JSON.stringify(this.student.hobby))
        let newHob = hob.filter((item) => {
            if(item !== '抽烟'){
                console.log(item);
                return item
            }
        })
        this.student.hobby = newHob; // 将Vue._data中的数据直接替换掉，触发页面更新
    }
}
```
