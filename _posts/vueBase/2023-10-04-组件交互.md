## 父传子 props

​	父组件传递给子组件的数据，子组件通过props接受后，不能直接更改该值。这是因为：

1. 所有的 prop 都使得其父子 prop 之间形成了一个单向下行绑定：父级 prop 的更新会向下流动到子组件中
2. 但是反过来则不行。这样会防止从子组件意外变更父级组件的状态，从而导致你的应用的数据流向难以理解


Step 1 — 父亲建立关系 

```js
import Child from './child';
componensts: { Child } // 引入组件
```

Step 2 — 父亲引用子组件

```js
<Child :bothSameName="inFatherDataVuale"><Child>
```

Step 3 — 孩子接受父消息

```js
props:{
	bothSameName:{
      type: String,
      default: undefined
    }
}
```

Step 4 — 孩子使用消息

```js
<p>{{bothSameName}}</p>
```

```html
// 父组件
<body>
    <div>
        <son :bothSameValueName="inFatherDataVuale" />
    </div>
</body>
<script>
    import son from './son' //引入子组件
    export default {
        name: 'Parent',
        components: { son },
        data() {
            return {
                inFatherDataVuale: 'Hi,my son！',
            }
        }
    }
</script>
```

```html
// 子组件
<body>
    <div>
        <p>父亲说：{{bothSameValueName}} </p>
    </div>
</body>
<script>
    export default {
        name: 'son',
        props: {
            bothSameValueName: {
                type: String,
                default: undefined
                //required:ture/false  是否是必须的
            }
        },
        data() {
            return {
                inSonDataVuale: this.bothSameValueName
            }
        }
    }
</script>
```

## 子传父 $emit

Step 1 — 孩子自定义事件

```js
this.$emit('SonSentToFather',this.number);
```

Step 2 — 父亲建立联系

```js
import Child from './child';
componensts: { Child } // 引入组件
```

Step 3 — 父亲使用子组件

```html
<Child @SonSentToFather='getNum'></Child> // 绑定的事件名：事件回调函数
```

Step 4 — 父亲定义函数接受参数

```js
methods:{
    getNum(val){ this.SonNum = val;}
}
```

```vue
// 父组件
<template>
	<son @SonSentToFather="getSonNum()" />
</template>

<script>
    import son from './son'
    export default {
        name: 'first_father',
        components: { son },
        data() {
            return {
                SonNum: ''
            }
        },
        methods: {
            getSonNum: function (val) {
                this.SonNum = val
            }
        }
    }
</script>
```

```vue
// 子组件
<template>
	<input type="text" v-model="a" @click="setLink" placeholder="传递给第一个父亲">
</template>

<script>
    export default {
        name: 'son',
        data () {
            return {
                number: 2992
            }
        },
        methods: {
            setLink: function () {
                this.$emit('SonSentToFather', this.number)
            }
        }
</script>
```

## 子传父 自定义事件

使用场景：子组件给父组件传值 — 父组件给子组件绑定自定义事件，子组件触发事件，回调函数在父组件中

1. 绑定事件 `$emit("eventName",parmas)`

2. 解绑事件 `$off("eventName")`

3. 监听事件 `$on("eventName",parmas)`

### $emit

   **给谁绑定事件，找谁触发事件，找谁解绑事件** 

![组件自定义事件.drawio](../assets/img/VueBase/组件自定义事件.drawio.png)

 

### $on

​	只触发一次 `$once` 或者 `eventName.once`

1. 自定义事件的回调函数，this指向被绑定、被触发的组件
2. 在当前组件调用methods定义的函数时，已当前组件函数的this为主
3. 生命周期钩子以普通函数方式定义，this一定取当前组件

```js
mounted(){
    this.$refs.children // 这里的this指向children组件
    .$on("eventName",this.getChildrenName) // 在当前组件调用methods定义的函数，以当前组件this为主
    
    this.$refs.children // 这里的this指向children组件
    .$on("eventName",function(name, ...params){ // 新定义的函数，指在children只能定义一个函数，参数取值都在children中
		console.log(this);
    })
    
    this.$refs.children // 这里的this指向children组件, 外层的this指向father
    .$on("eventName",(name,...params)=>{ // 箭头函数往外层找this
        this.sonValueName = name;
    })
}
```

【总结】使用`$ref`为组件绑定自定义事件时，必须关注`this`的指向 — 回调要么配置在methods中，要么使用箭头函数

### $off

1. 解绑一个

```js
this.$off('eventName');
```

2. 解绑多个 — **必须写在数组中**

```js
this.$off(['eventName1','eventName2']);
```

3. 解绑全部

```js
this.$off();
```

## 兄弟间传值 EventBus

:warning: 兄弟彼此之间没有联系，使用Vue实例作为Bus数据传递

Step １ — 建立Bus

```js
import Vue from 'vue
export default new Vue()
```

Step ２ — 兄弟上车

```js
import eventBus from './EventBus"
```

Step ３ — 接收方配置

```js
created() { // 创建时就打开通道，或 mounted时刻监控
    eventBus.$on('pushMsg', (sendMsg) => {
        this.getMsg = sendMsg;
    })
}
```

Step ４— 发送方配置

```js
methods: {
    pushMsg(){
        eventBus.$emit('pushMsgTage',this.sendMsg);
    }
}
```

```html
// 发送方
<script>
    import eventBus from './EventBus';
    export default {
        name: 'SendSide',
        components: {},
        data() {
            return {
                sendMsg: ''
            }
        },
        methods: {
            pushMsg() {
                eventBus.$emit('pushMsgTage', this.sendMsg);
            }
        }
    }
</script>
```

```html
// 接收方
<body>
    发送方 传过来的消息： {{getMsg}}
</body>
<script>
    import eventBus from './EventBus';
    export default {
        name: 'getSide',
        components: {},
        data() {
            return {
                getMsg: ''
            }
        },
        created() {
            eventBus.$on('pushMsgTage', (sendMsg) => {
                this.getMsg = sendMsg;
            })
        }
    }
</script>
```

## 兄弟间传值 全局事件总线（GlobalEventBus）

​	适用于任意组件间的通信

![组件间传值-事件总线](../assets/img/VueBase/组件间传值-事件总线.jpg)

①所有组件都能看到它  的有三种：

1. window — 不应该修改
2. VueComponent — 仅一个构造函数，需要调用Vue.extend生成 
3. vc — 每次生成都是一个新的实例，互不关联
4. **Vue  — 将x放在 Vue的原型对象上 `Vue.prototype`**

**`VueComponent.prototype._proto_ === Vue.prototype`** 组件实例对象Vc可以访问到Vue原型上的属性、方法

![VM&VC原型链关系.drawio](../assets/img/VueBase/VM&VC原型链关系.drawio.png)

②它可以调用所有组件的事件：

1. 基础数据类型，不含括`$on` `$off` `$emit`

2. VueComponent — vue实例vm无法调用

   1. const Demo = Vue.extend({config})  — Demo 是Vue.extend生成一个VueComponent 构造函数
   2. const demo = new Demo — demo 是通过new 创建的vc实例对象
   3. 相当于在页面中引入一个组件`<vm />`
   4. Vue.prototype.x = demo — Vue的原型对象上配置一个vc对象，拥有调用组件事件的函数

3. vue实例

   1. Vue 创建前绑定，没有vue实例对象可以赋值；Vue 创建完成后绑定，页面已经完成挂载，子组件调用不到

   2. Vue `beforeCreate()`时绑定，且指向自身（无需新增变量）

      初始化时，Vue数据检查、数据代理未开始，页面未挂载

❗ 定义

```js
new Vue({
    el:"#app",
    render: h=>h(App),
    beforeCreate(){
        Vue.prototype.$bus = this // 安装全局事件总线
    }
})
```

```js
export default{
    name:"",
    methods:{
		sendMsg(){
            this.$bus.$emit('hello', name) // 在全局事件总线上绑定事件，sendMsg触发
        }
    }
}
```

❗ 使用

```js
mounted(){
    this.$bus.$on('hello',(data) =>{ // 监听事件，事件调用放在调用者身上
        console.log('接受到数据',data)
    })
    beforeDestroy(){
        this.$bus.$off('hello'); // 当前组件销毁前，解绑事件（下车，把位置让给别人坐）
        this.$bus.$off(); // 清空全局事件总线 （整个车子都没有座位了）
    }
}
```
